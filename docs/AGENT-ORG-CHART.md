## Agent Communication Protocol

### Synchronization Points
1. **Research Complete** → VP reviews all research documents
2. **Architecture Approved** → Engineering can begin
3. **Module Complete** → Testing Agent validates
4. **Tests Pass** → Code Review Agent reviews
5. **Review Approved** → Validation Agent final check
6. **Validation Pass** → VP approves merge

### Parallel Work Boundaries
- Frontend and Backend work in parallel after architecture approval
- Individual game engines can be built in parallel
- Tests are written alongside implementation (TDD where possible)
- Each agent owns specific directories to prevent conflicts

### Conflict Prevention
- Shared types defined in `/src/shared/types/`
- Only Architecture Agent modifies shared types
- Component ownership clearly defined
- PR reviews required before merge
