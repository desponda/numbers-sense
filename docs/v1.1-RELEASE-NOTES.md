## What's New

### Game 3: More Than / Less Than

A pedagogically-designed game addressing a common learning gap: children struggling with "N more than" and "N less than" problems, especially with larger numbers like "4 less than 73".

#### Four Difficulty Levels

| Level | Number Range | Visual Support | Target Grade | Example Problem |
|-------|-------------|----------------|--------------|-----------------|
| **Easy** | 1-10 | Full blocks always shown + number pad | K-1 | "2 more than 5 = ?" |
| **Medium** | 5-30 | Peek button (3 uses, 5sec reveals) | 1-2 | "10 more than 14 = ?" |
| **Hard** | 10-100 | Strategy hints, optional blocks | 2-3 | "4 less than 73 = ?" |
| **Challenge** | 1-100 | Mental math only, multi-step | 3+ | "5 more than (3 less than 12) = ?" |

#### Key Features

**Visual Scaffolding**:
- Animated block displays using existing UnitCube/TenRod/HundredFlat components
- Addition animation: Scales in with fade (400ms)
- Removal animation: Fades out with strikethrough (300ms)
- Color-coded: Teal (starting), Coral (added), Gray (removed)

**Progressive Feedback System**:
- **Attempt 1**: Gentle encouragement - "Not quite. Try again!" (warm orange, no harsh red)
- **Attempt 2**: Specific hint based on error type detected
- **Attempt 3**: Shows correct answer with explanation

**Error Detection** (5 Types):
1. Reversed operation (added instead of subtracted or vice versa)
2. Wrong order (computed 4-7 instead of 7-4)
3. Counting error (off by ±1)
4. Place value error (added to wrong digit)
5. Teen number confusion (misinterpreted 13-19)

**Adaptive Difficulty**:
- Tracks rolling 10-problem accuracy
- Adjusts operation size based on performance
- Easier if accuracy <60%, harder if >90%

## User Experience Improvements

### Fixed Issues

1. **Critical**: Removed premature answer reveal in visual scaffold
   - Previously showed "Result: 17" before child attempted answer
   - Now hides result until after submission

2. **Critical**: Fixed undefined Tailwind color class
   - Changed `text-coral-500` to `text-orange-500`
   - Ensures proper emphasis color rendering

### Design Decisions

**Progressive Scaffolding**:
- 3 attempts before showing answer (research-backed optimal)
- Hints become more specific with each attempt
- No punishment for wrong answers (builds confidence)

**Visual Design**:
- Large, clear text (28-36px)
- Calm, muted colors (60-80% saturation)
- Non-overstimulating animations (150-800ms timing)
- Joyful but not distracting

**Accessibility**:
- ARIA labels on all interactive elements
- Keyboard navigation (Enter to submit)
- Screen reader announcements for feedback
- Focus management for modal interactions
